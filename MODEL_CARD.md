# Evaluation and limits

Read the report's source and selection fields before quoting results. Test results are conditional on the chosen split, features and modeling decisions. No claim of production deployment or hiring readiness is made. All code is newly built; use actual project dates. Understand and modify the implementation before presenting it.

Results are reproducible within numerical tolerance with seed 42. `environment.json` records the versions used for the included run. Broad requirement bounds are not a fully frozen lockfile. No model is loaded from an external pickle. CI executes behavior tests. Raw downloaded datasets are excluded from git and the distribution.
